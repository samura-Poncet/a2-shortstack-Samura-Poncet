
## Find your zodiac sign!

My project takes in a user first name, last name, and date of birth to find their zodiac sign. After the user inter their info they click the find my zodic sign button and their zodiac sign shows at the bottom along with the symbole for each sign. 
In my server.js I've included the dates for each zodia along with the symboles. 
CSS positioning: CCS grid to center elements on the page. 
To use the application enter the required information(first name, last name, birthday) and click "Find my zodiac sign"
